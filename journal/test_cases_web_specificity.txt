TEST CASES: WEBSITE PRIMER DESIGNER (specificity and GC)
=========================================================
Website:  website/index.html (also https://claude.ai/artifact/XKd9SSGhpFHH1WXYemP3Bh)
Designer: website/primer_design.js = journal/primer_design.py translated
Checked:  every expected result below was produced by primer_design.py;
          python3 journal/check_website_port.py checks the website gives
          the same

How to run a case: copy the GENOME block into the Genome box and the TARGET
GENE block into the Target gene box (line breaks are fine), set the mismatch
allowance, leave the product length range at 60 to 150 (the default), and
press "Suggest primers". Or skip the copying: the website's "Case 1" to
"Case 5" buttons load these same sequences and run them.

Every fake genome is built the same way:
  100 random bases + 200-base target + 100 random bases     (400 bases)
  Cases 2-4 add 50 more random bases + a SECOND COPY of the target (650
  bases). How closely the copy matches the target is what the case tests.
  The target is always genome positions 101-300.

What the five cases cover:

  Case  Target GC            Second copy of the target         Covers
  1     46.0 % (good)        none                              good GC, no matches elsewhere
  2     30.5 % (low)         every 6th base changed            low GC, > 2 mismatches
  3     66.0 % (high, ok)    every 12th base changed           high-but-ok GC, <= 2 mismatches
  4     45.5 % (good)        exact copy                        perfect matches elsewhere
  5     89.0 % (too high)    none                              high GC (error)

Why the copies give those mismatch counts: primers are 18-24 bases.
  every 6th base changed:  any 18-24 bases cover 3 or 4 changes -> always
                           more than 2 mismatches, so the copy never counts
  every 12th base changed: any 18-24 bases cover 1 or 2 changes -> within
                           an allowance of 2, so every primer also binds the
                           copy

GC bands: every primer and probe must be 40-60 % GC. Target above 70 % ->
error; 60-70 % -> "medium" warning; below 40 % -> "low" warning.
Ranking: penalty = each oligo's distance from 50 % GC + (product - 60) / 10,
so shorter products rank higher.
Positions are 1-based. Reverse primers are listed as ordered (5'->3').
