TEST CASES: PRIMER DESIGN (version 3)
======================================
Designer: journal/primer_design.py
Tests:    journal/test_primer_design.py
Run:      python3 journal/test_primer_design.py   (15 cases)
Real-data check: CDC N1/N2/N3 (see the end of this file)

The designer takes a genome, a target gene inside it, a mismatch allowance
(0-2) and a product length range (default 60-150 bp), and returns up to 3
designs: a
forward primer, a reverse primer and a probe. It uses only what the first
model uses (sequence, mismatch allowance, binding sites on both strands,
product length, probe inside the product), plus GC content. No melting or
annealing temperature.

Fake genome (the same every run: seeded random bases):
  2,000 random bases (seed 1, 50 % GC)
  + 400-base target (seed 3, 45.3 % GC)
  + 2,000 random bases (seed 2, 50 % GC)
  Target = genome positions 2001-2400 (1-based)
  Target starts GCATGCTGGTAGGTTTCAACCTCTTAATAATGTGGCAGCTAGGTCGTGTCATGTTATGCT...

Rules every returned design must follow (checked for every design):
  - forward = the genome window; reverse = reverse complement of its window;
    probe = the genome window
  - primers 18-24 bases, probe 18-30 bases, all inside the target
  - each oligo's length = the one with GC closest to 50 % (shorter on a tie)
  - every primer and probe 40-60 % GC
  - probe between the primers, overlapping neither
  - product inside the chosen range (default 60-150 bp; never below 54 bp)
  - independent check: run_model (first model) on the whole genome with the
    designed oligos finds exactly ONE product, status "product", at the
    designed place

Ranking, best match first:
  penalty = |forward GC - 50| + |reverse GC - 50| + |probe GC - 50|
            (percentage points)  +  (product - shortest allowed) / 10
  Lower is better, so shorter products rank higher; ties go to the earlier
  start. Each later design's product
  must not overlap an earlier one.

Target GC (checked first, before anything else runs):
  above 70 %   error with the reason; the design stops
  60-70 %      warning (medium)
  below 40 %   warning (low); SARS-CoV-2 as a whole is about 38 % GC
  40-60 %      no message

Positions below are 1-based (genome position 1 = first base).
"pen" = match penalty.


CASES THAT SHOULD GIVE DESIGNS
------------------------------

Case 1 - Basic: 400-base target in a 4,400-base genome
  Allowance 2, product range 60-150 bp
  Outcome:  target found at 2001-2400, + strand; 13,127 possible designs,
            3 checked, 3 kept, no warnings
    Design 1  F 5'-GGTCGTGTCATGTTATGC-3'            2042-2059  18 nt, 50 %
              R 5'-CCATAGTACGGAGAATACCC-3'          2082-2101  20 nt, 50 %
              P 5'-ATTTGCTCGAGTGACAGG-3'            2063-2080  18 nt
              product 2042-2101, 60 bp, pen 0.00
    Design 2  F 5'-GTGCCAGAGTTCAGTAAG-3'            2264-2281  18 nt, 50 %
              R 5'-TCCTTCAGAAGACCTGTC-3'            2309-2326  18 nt, 50 %
              P 5'-TATCCTCTCCAACCAGAAGG-3'          2285-2304  20 nt
              product 2264-2326, 63 bp, pen 0.30
    Design 3  F 5'-CCACTAGCTTTTCACCAC-3'            2175-2192  18 nt, 50 %
              R 5'-CGACTATACGTTGATGAAAGGGGG-3'      2216-2239  24 nt, 50 %
              P 5'-TAAATGAGTGCGCTCTCC-3'            2196-2213  18 nt
              product 2175-2239, 65 bp, pen 0.50
  Meaning:  Every rule holds and the first model agrees each design gives
            only one product. The products do not overlap. Each is close to
            the shortest allowed length (60 bp), because shorter ranks higher.

Case 2 - Ranking, best match first (worked out by hand)
  Hand example (range 60-150):
                forward 9/20 G = 45 % -> 5 points
                reverse 10/20 G = 50 % -> 0
                probe 11/20 G = 55 % -> 5
                product 80 bp -> (80 - 60) / 10 = 2
                penalty = 5 + 0 + 5 + 2 = 12
  All three 50 %: 60 bp -> penalty 0; 150 bp -> penalty 9.
  Real run: design 1 has every oligo at 50 % and a 60 bp product -> penalty
            0, the best possible. Penalties come out in order: 0.0, 0.3, 0.5.

Case 3 - Target given as its reverse complement
  Outcome:  target found on the - strand at 2001-2400; same designs as Case 1
  Meaning:  A gene can be pasted from either strand.

Case 4 - Genome and target pasted as FASTA, lowercase, 60 bases per line
  Outcome:  same designs as Case 1
  Meaning:  ">" header lines, line breaks and lowercase letters are cleaned
            away before the search.

Case 5 - 30 N bases in the middle of the target (genome 2181-2210 = N)
  Outcome:  8,975 possible designs; 3 designs: products 2042-2101 (pen 0.00),
            2264-2326 (pen 0.30), 2330-2396 (67 bp, pen 2.87);
            no primer or probe contains N
  Meaning:  Missing data is never put into an oligo (the first model would
            call such a site "not assessable"). Case 1's design 3
            (2175-2239) is gone: it sits on the N block.

Case 6 - A 40-base all-G/C stretch inside an ordinary target
  (genome 2101-2140 replaced by random G/C)
  Outcome:  target GC 50.5 %; 9,756 possible designs; the same 3 designs as
            Case 1; every oligo 40-60 % GC
  Meaning:  The G/C stretch is skipped even when the target as a whole is
            fine. None of Case 1's designs touch 2101-2140, so they stay.


SPECIFICITY (the first model's job)
-----------------------------------

Case 7 - The target appears twice in the genome
  (genome = Case 1 genome + a second exact copy of the target at the end)
  Outcome:  no design; all 13,127 possible designs checked, every one fails
  Meaning:  Every primer binds both copies, so no design is specific.

Case 8 - A second copy with every 12th base changed (A->C, C->G, G->T, T->A)
  Worked:   Any 18-24 bases in a row cover 1 or 2 changed bases (one in
            every 12), so every primer matches the copy with at most 2
            mismatches.
  Allowance 2:  no design (all 13,127 checked; every primer binds the copy)
  Allowance 0:  3 designs, the same as Case 1, all passing every rule
  Meaning:  The mismatch allowance decides what counts as an off-target
            site, exactly as in the first model.


GC CONTENT
----------

Case 9 - Target 80.0 % GC (400 random bases, seed 9)
  Outcome:  ERROR: the target's GC content is 80.0 %, above 70 %: primers
            here would bind too strongly, also at partly matching sites, and
            the GC-rich template folds on itself and copies poorly. Choose a
            less GC-rich target.

Case 10 - GC-rich target that is NOT in the genome (seed 10, 80.2 % GC)
  Outcome:  the GC error above, not "the target gene is not in the genome"
  Meaning:  The GC check really runs first, before the target is even
            looked up.

Case 11 - Target 65.5 % GC (seed 11)
  Outcome:  WARNING: target GC content is 65.5 % (medium, above 60 %):
            primers may bind more strongly than intended; check the designs
            before ordering
            2,586 possible designs; 3 returned, products 2338-2397 (60 bp,
            pen 5.56), 2027-2097 (71 bp, pen 6.66), 2117-2241 (125 bp,
            pen 22.06)
  Meaning:  A medium target is a warning, not an error. Fewer stretches
            reach 40-60 %, so the penalties are higher than in Case 1.

Case 12 - Target 28.0 % GC (seed 12)
  Outcome:  WARNING: target GC content is 28.0 % (low, below 40 %): fewer
            stretches reach 40-60 % GC, so there may be fewer designs
            121 possible designs; 1 returned, product 2290-2362, 73 bp,
            pen 10.39
  Meaning:  An AT-rich target is a warning, not an error, and a design can
            still be found inside it.

Case 13 - Target with no stretch at 40-60 % GC ("ATTA" x 50, 0 % GC)
  Outcome:  0 possible designs, no design; warnings:
            target GC content is 0.0 % (low, ...)
            no design: the target has no forward, reverse and probe
            stretches with 40-60 % GC that fit together into a 60-150 bp
            product
  Meaning:  When nothing can be designed, the output says GC is why.


PRODUCT LENGTH
--------------

Case 14 - The user chooses the product length range
  70-90 bp:  3,353 possible designs; 3 designs, products 2037-2106 (70 bp,
             pen 0.0), 2258-2327 (70 bp, pen 0.0), 2175-2245 (71 bp,
             pen 2.73); no warning
  250-350 bp: 1 design (only one product that long fits in 400 bases
             without overlapping), product 2077-2326, 250 bp, pen 0.0
             WARNING: the product range 250-350 bp goes outside 60-150 bp,
             where qPCR works best
  Meaning:  Designs stay inside the range, and the shortest allowed length
            wins when GC is equal.


BAD INPUT
---------

Case 15 - Errors with a reason
  Target not in the genome  -> the target gene is not in the genome
                               (checked both strands)
  Allowance 3               -> mismatch allowance must be 0 to 2
  Allowance -1              -> mismatch allowance must be 0 to 2
  Range 53-150              -> the shortest product must be at least 54 bp
                               (room for an 18-base forward primer, probe
                               and reverse primer)
  Range 150-60              -> the longest product (60 bp) is shorter than
                               the shortest (150 bp)
  59-base target, 60-150    -> the target (59 bases) is shorter than the
                               shortest product asked for (60 bp)
