How the designer chooses
  • Primers are 18–24 bases, the probe 18–30. At each position the length with GC closest to 50 % is used.
  • Every primer and probe must be 40–60 % GC. The target's GC is checked first: above 70 % stops the design, 60–70 % or below 40 % gives a warning.
  • The probe sits in the middle of the gap between the primers.
  • Ranking, best match first: penalty = the three oligos' distance from 50 % GC (percentage points) + (product length − shortest allowed) ÷ 10, so shorter products rank higher. Lower is better.
  • A design is kept only if each oligo binds exactly once in the whole genome and the first model finds exactly one product, with the probe inside it. Later designs do not overlap earlier ones.
  • Not considered: melting temperature, hairpins and primer dimers.
Positions are 1-based genome coordinates. The reverse primer is shown 3'→5' so it lines up under the genome; order it 5'→3' as listed.
